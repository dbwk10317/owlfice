사무실 확장안

조명 4단계 · 방 10개의 소품 확장 · 새 방 4개 · 테마. 모두 세션 파일에서 확인되는 신호에만 묶는다 (CONTRACTS C13).

조명 4단계 · 같은 장면에 곱하기 색만 바꾼다 floorplan.lightTints

주간 · 09–17시 · #FFFFFF
저녁 · 17–20시 · #F6E6C4 (새로)
야근 · 20시 이후 · #F2DEAD + 비네트
소등 · 모두 퇴근 · #6E6E82

저녁 단계를 하나 더 두어 시간이 흐르는 느낌을 준다. 창문 컨테이너는 그대로 제외하고, 야근에는 책상 램프 주변만 밝게 남기는 비네트 레이어(`overlay`)를 얹는다. 기준 시각은 OS 로컬 시계 (확인됨).

방별 소품 확장 · 신호 → 소품

팀장석기존

turn count · session age · context%
  • 책상 램프 야근 모드에 켜짐
  • 커피 잔 쌓임 근속 1h마다 1잔, 최대 4
  • 명패 금속화 세션 3h 이상
  • 화분 성장(컨텍스트)은 그대로

개발실기존

Edit/Write 횟수 · parallel calls
  • 모니터 2대 병렬 호출 중인 직원
  • 책상 위 서류 더미 수정 파일 10개마다 1단
  • 파티션 포스트잇 할 일(TodoWrite) 개수
  • 키보드 LED type 자세에서만

소스 서고기존

Read/Grep/Glob · 파일 수
  • 책장 채움 읽은 파일 수 비례 (0·25·50·100)
  • 사다리 1000줄 넘는 파일 열람
  • 사서 데스크 램프 검색 중

빌드실 · 테스트실기존

Bash · exit code · duration
  • 서버 랙 LED 색 성공 초록 / 실패 빨강 / 진행 노랑
  • 환풍기 평균 2배 초과
  • 합격 도장 벽 연속 통과 n회 → 트로피
  • CI 전광판 오늘 성공/실패 수

리뷰실기존

코드 리뷰 문구 · 지적 수
  • 빨간 포스트잇 지적마다 (기존)
  • 초록 포스트잇 승인 문구
  • 리뷰 소파 사람 수 리뷰 중 직원 수

거래처 미팅실기존

MCP 서버 이름 · 스킬 이름
  • 명함 꽂이 오늘 쓴 MCP 서버 수
  • 화상회의 화면 로고 글자 서버 이름 (BitmapText)
  • 스킬 매뉴얼 책 색 스킬별 해시 색

출고장기존

git commit · push · PR
  • 상자 쌓임 오늘 커밋 수
  • 트럭 색 PR 열림 파랑 / 머지 초록
  • 반송 상자 push 실패 (기존)
  • 불꽃놀이 릴리스 (기존)

장애 상황실 · 탕비실기존

error events · idle time
  • 경광등 회전 장애 진행 (기존)
  • 화이트보드 글자 수 사고 누적
  • 탕비실 TV 게임 화면 쉬는 직원 수
  • 피자 상자 야근 2h마다 1단

회의실새 방

plan mode · EnterPlanMode/ExitPlanMode
  • 부장이 화이트보드 앞에 서서 계획 작성
  • 계획 승인되면 박수 후 복귀
  • 카드: "계획 세우는 중"

자료실새 방

compaction · summary 이벤트
  • 직원이 서류를 파쇄기에 넣는 연출
  • 컨텍스트 막대가 줄어드는 순간과 동기화
  • 카드: "서류 정리 중 (컨텍스트 정리)"

경비실새 방

permission denied · hook block
  • 출입문 옆 경비 창구. 거부되면 직원이 멈춰 서서 결재판을 든다
  • 훅이 막으면 차단봉 내려감
  • 카드: "출입 거부 · 훅"

옥상 휴게 공간새 방

사용자 응답 대기 30분 이상
  • 벽 위 옥상 조각이 보이고 직원이 올라가 자판기 커피
  • 탕비실이 꽉 찰 때의 둘째 쉬는 자리
  • 추정 꼬리표 그대로

  • 12월 입구 작은 트리, 책상 위 양말 1개. 설·추석 벽 등 1개
  • 비·눈은 날씨 데이터가 없으므로 넣지 않는다 (미확인 → 제외)
  • 스프라이트는 `office.json`에 `season/<이름>` 상태로만 추가, 평면도는 그대로
