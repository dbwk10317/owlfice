# 시나리오 번호표

코드·dev 페이지·스프라이트 규칙에서 쓰는 사용자 관점 동작의 번호표다. 번호가 있다는 것만으로 구현·검증 완료를 뜻하지 않는다. 각 번호의 실제 동작은 [CONTRACTS](CONTRACTS.md) 와 코드가 기준이며, 이 표는 번호가 어떤 상황을 뜻하는지 찾는 용도다. 조건부 지원을 구현하지 않은 번호는 해당 코드 주석이 밝힌다. 화면 표현은 [HANDOFF 5절](../design/HANDOFF.md#5-상태--화면-대응)을 따른다.
