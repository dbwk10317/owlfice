시트 규격 · 파일 구조 · 코드 접점

동물은 시트 단위로 바꿉니다. 세 시트가 프레임 키·메타 구조를 똑같이 가지므로 앱은 "어느 시트를 읽을지" 한 줄만 바꾸고, 나머지는 이미 메타를 읽는 코드가 그대로 돕니다. 밀도 2배에 닿는 코드는 네 군데입니다.

프레임 키 (두 밀도 공통, 2,117장)
  body/<종>/<자세>_<방향>_<번호>     종 18 × 37 (올빼미·강아지·고양이 각 6)
  outfit/<옷>/…  wear/<1|2|3>/…  role/<담당>/…  item/<소지품>/…

owlfice 메타 (시트마다)
  frame: [32, 48]          anchor: [16, 46]
  density: 2               ← 새 키. 월드 px 당 텍셀 수
  layers / layerRule / wear / outfits / roles / poses   그대로
  species: { 18종 이름 }   animals: { owls|dogs|cats: { name, employees[5], boss } }
  employeeSpecies: [15종]  ← 섞기면 hash % 15, 한 동물이면 animals[동물].employees 의 hash % 5
  bossSpecies: ["snowy", "samoyed", "persian"]   ← 섞기면 hash(team_id) % 3
  anchors[자세]: { head: [16, 16], hand: [26, 38] }   ← 텍셀 단위 (×2)
  • 생성기. owlfice_art.py 의 종 표에 품종 12개를 더하고, 몸통·날개·옷·소지품 셀을 2×2 블록으로 찍은 뒤 얼굴(눈 상자·눈썹·입·무늬)만 1px 격자로 얹는다. 자세 기하(pose_geo)와 레이어 함수는 재사용. 시트 3장을 한 번에 만들고 끝에 겹침·누락 검사.
  • 시트 크기. 1,673장 × 33×49 ≈ 2.7M 텍셀 → 2048×2048 한 장 (목표). 셋 합쳐 PNG 약 150KB (목표).
  • 미리보기·참조 렌더. preview/*.png 와 assets/office-*.png 는 올빼미 2×를 반영해 다시 만든다. 참조 렌더는 1× 장면에 0.5 배 nearest 합성 — 배율 1 픽셀 비교(HANDOFF 6.7)는 그대로 유효.

바꾸지 않는 것 계약 유지

  • 자세 18가지, 프레임 수, fps, 우선순위 (HANDOFF 5.3 · 6.4)
  • 레이어 5개와 겹치는 순서, worn 옷, 근속 1·2·3 규칙
  • 직원 종 해시 규칙, 담당 8 + 수습, 소지품 4 + held 3
  • 평면도·좌석·서 있을 자리·조명·창문 등 사무실 전부
  • 카드·행·팝업 UI 와 토큰. 아바타 칸 크기(44 · 88)

작업 순서 제안 티켓

  • 1. 생성기: 올빼미 6종 2× + 얼굴 규칙 + 메타 (density · bossSpecies · anchors ×2). 미리보기 재생성
  • 2. 렌더러·아바타 접점 4곳. 참조 렌더 비교 녹색
  • 3. 강아지·고양이 종 표 12개, dogs/cats 시트 생성, 겹침·누락 검사
  • 4. 설정 "직원 동물" + 시트 경로 선택 + 재로드
  • 5. 1×·2×·3× 실제 창에서 눈·표정 가독 검수 (사람)

가정 · 확인 필요 미확인

  • 가정 동물은 사무실 전체가 하나 (설정). 한 사무실에 섞지 않는다. 섞으려면 세 시트를 함께 읽고 employeeSpecies 를 잇는 변형이 되며 이번 범위 밖
  • 가정 배율 3 에서 1.5배 확대(고르지 않은 픽셀)를 받아들인다. 싫으면 3× 시트 한 벌 추가 (해상도 보드)
  • 미확인 2048×2048 텍스처가 대상 GPU 전부에서 안전한지 (목표값). 넘치면 레이어별 시트 분리
  • 미확인 품종 이름·색은 시안. 사용자 확인 뒤 생성기에 옮긴다
  • 가정 올빼미 품종 실루엣은 지금 것을 2× 그대로 (사용자가 알아보는 얼굴 유지), 얼굴만 다시 그림
