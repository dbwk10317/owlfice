# 규칙

같은 실수가 두 번 이상 난 것만 적는다 (AGENTS 7절). 상황 → 규칙 → 이유.

## CSS 초기화는 특이성 0 으로

- 상황: `tokens.css` 의 `.ow-app button { padding: 0; margin: 0 }` 이 `<button>` 으로 만든 카드·행·그룹·`.ow-btn` 의 padding·margin 을 이겼다. 티커 항목에서 한 번(선택자를 한 단계 더 써서 우회), 현황판·사이드바 전체에서 또 한 번(T52).
- 규칙: 요소 선택자로 쓰는 초기화는 `:where(...)` 로 감싸 특이성 0 으로 둔다. 컴포넌트 쪽에서 선택자를 더 붙여 우회하지 않는다.
- 이유: 컴포넌트는 `<button>` 인지 `<div>` 인지가 바뀌어도 같은 클래스 규칙으로 보여야 한다. 우회 선택자는 다음 컴포넌트에서 같은 버그를 다시 낸다.
